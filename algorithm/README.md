# Algorithm Contests

AtCoderのアルゴリズム系コンテストで作成したコード。

## File Names

- `<problem>.py`: 自分の提出コード、または最初に保存した自作解法
- `<problem>_alternative.py`: 自分で書いた別解
- `<problem>_reimplementation.py`: 解説を理解した後、コード表現をコピーせず独立して書いた実装

同じ種類が複数ある場合は、末尾に`_1`、`_2`を付加。1ファイルにつき1つの実行可能な解法を基本とする。

公式解説や第三者解説は参照URLだけを記録し、本文、画像、サンプルコード、写経、言語翻訳は収録しない。
