# Heuristic

AtCoder Heuristic Contestの提出コードと実験記録のためのディレクトリ。

## Structure

```text
ahc/
  ahcxxx/
    main.py      提出コード
    README.md    方針、スコア、試行内容
    tools/       ローカルテスタや補助スクリプト
    in/          生成した入力
    out/         実行結果
    logs/        スコアや実行ログ
```

`in/`、`out/`、`logs/`、ビルド時の`target/`はGit管理外。
