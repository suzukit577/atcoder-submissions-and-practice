# AtCoder Submissions and Practice

AtCoderのコンテスト中に提出したコード、コンテスト外で取り組んだ問題の練習コード、競技プログラミング用のライブラリをまとめた個人用リポジトリです。過去のコードは、当時の理解や実装方法を振り返るための記録として保存しており、現在なら異なる実装方針を選択するコードや、改善の余地があるコードも含まれます。競技成績・実装の完成度を示すポートフォリオや、模範解答集としての公開は目的としていません。

現在は、主にAtCoder Beginner Contestへ参加した際のコードを収録しています。コンテスト外の過去問演習も記録し、AtCoder Heuristic Contestへ参加した場合はアルゴリズム系コンテストと分けて保存します。現時点では、ヒューリスティック系コンテストのコードは収録されていません。

## ディレクトリ構成

```text
.
├── algorithm/  # 実際に参加したアルゴリズム系コンテストの提出コードと別解
├── heuristic/  # 実際に参加したヒューリスティック系コンテストの提出コードと実験記録
├── training/   # コンテスト外で取り組んだ過去問や問題集などの練習コード
├── mylib/      # 継続的に保守・テストする再利用コード
├── snippets/   # mylib/から生成したVS Code用スニペット
├── scripts/    # リポジトリの整理や生成処理に使うスクリプト
└── tests/      # mylib/と整備スクリプトのテスト
```

## 記録と保守の方針

`algorithm/`、`heuristic/`、`training/`のコードは、コンテスト参加時または練習時の記録として扱います。過去コードの一括整形や、現在の書き方に合わせたリファクタリングは原則として行いません。

継続的に保守するのは、主に`mylib/`、`scripts/`、`snippets/`、`tests/`です。再利用コードを変更した場合は、関連するテストとVS Codeスニペットも更新します。

1つのファイルには、原則として1つの実行可能な解法を保存します。自作の別解を追加する場合は、元の提出コードとファイルを分けます。

収録したコードは個人の学習記録であり、正しさ、最適性、汎用性を保証するものではありません。

## 使用環境

| 項目 | 内容 |
| --- | --- |
| 主な提出言語 | Python |
| AtCoder提出環境 | CPython 3.13系、PyPy 3.11系 |
| ローカル実行環境 | Python 3.13、ルートの`.venv/` |
| 依存関係管理 | uv、`pyproject.toml`、`uv.lock` |
| 競技用ライブラリ | NumPy、Sorted Containers、AtCoder Library for Python |
| エディタ | VS Code |
| 品質管理 | unittest、Ruff、mypy |

過去の提出記録の一部には、C/C++コードも含みます。現在のリポジトリ管理とライブラリの保守には、主にPythonを使用しています。

ローカル環境はAtCoderのジャッジ環境を完全には再現していません。インタプリタ、利用可能なライブラリ、実行制限は変更される可能性があるため、提出時には対象コンテストのルールと[AtCoderで使用できる言語・ライブラリの公式一覧](https://img.atcoder.jp/file/language-update/2025-10/language-list.html)を確認します。

## コードの所有と出典

`algorithm/`、`heuristic/`、`training/`には、自身が作成した解法コードだけを収録します。
`mylib/`、`scripts/`、`tests/`、文書などのリポジトリ整備には、生成AIによる支援を含む場合があります。

AtCoderの問題文や画像、公式解説や第三者解説の本文、サンプルコード、写経、言語翻訳は収録しません。公式解説や第三者解説を参照した場合は、必要に応じて参照先のURLのみを記録します。

## 生成AIの利用方針

競技プログラミングに取り組む主な目的は、「自身の問題解決力とコーディング力を高めること」および「アルゴリズムとデータ構造への理解を深めること」であるため、問題文の理解、解法の検討、アルゴリズムやデータ構造の選択、提出・練習コードの作成、デバッグ、計算量の改善には生成AIを使用しません。過去問を使った練習においても同じ方針を適用します。

生成AIを使用するのは、リポジトリの構成整理、ファイル管理、文書や設定の整備、スニペット用ライブラリの保守、テスト、VS Codeスニペットの生成に限ります。

開催中のコンテストでは、参加時点の公式規則を最優先します。生成AIの使用が禁止されるコンテストでは、生成AIを一切使用しません。

2026年10月4日時点では、開催中のABC・ARC・AGCと短期AHCで生成AIの使用が原則として禁止されています。長期AHCには別の利用規則が適用されるため、参加時に最新の規則を確認します。

- [ABC・ARC・AGCの生成AI対策ルール](https://info.atcoder.jp/entry/llm-rules-ja)
- [短期AHCの生成AI利用ルール](https://info.atcoder.jp/entry/short-ahc-llm-rules-ja)
- [長期AHCに適用される生成AI利用ルール](https://info.atcoder.jp/entry/ahc-llm-rules-ja)
